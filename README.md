# 🌿 BreezeAtlas 2026 — Global Country & Weather Intelligence App

**BreezeAtlas 2026** is a production-ready, zero-API-key, single-file HTML5 Weather & Global Country Intelligence web application built with **Eye-Soothing Biophilic Glassmorphism**, **Live World Clock & Timezone Synchronization**, and an **Interactive 2026 Forecast & Planner Calendar**.

---

## ✨ Key 2026 Features (What Makes It Different)

1. **🌍 Country-First Smart Search (`REST Countries` + `Open-Meteo Geocoding`)**
   - Type **any Country name** (e.g., *India, United Kingdom, Japan, Switzerland, UAE, Canada, Brazil, Australia*) or **any City** worldwide.
   - Automatically displays the **Country Flag, Capital City, Currency, Population, Official Languages, Region**, and **One-Click Major City Pills** inside that country.
2. **🎨 5 Eye-Soothing Biophilic Color Palettes**
   - **Aurora Sage** (Soft Teal & Deep Slate)
   - **Lavender Mist** (Calming Violet & Cyan)
   - **Matcha Zen** (Botanical Forest Green)
   - **Sunset Silk** (Warm Amber & Rose Dusk)
   - **Nordic Daylight** (Soft High-Clarity Light Mode)
3. **🕰️ Sidebar Live Dual-Timezone World Clock**
   - Real-time **Analog + Digital Chronometer** showing the exact live time in the selected Country/City (`UTC` offset + Daylight/Nighttime indicator) alongside your own device's local time and time difference.
4. **📅 Sidebar Interactive 2026 Weather & Travel Calendar**
   - Displays live weather emojis directly inside calendar dates (5 days past + 11 days forecast).
   - Click any date on the calendar to inspect that day's forecast, or save **Personal Travel / Weather Reminders** (persisted in `localStorage`).
5. **📈 24-Hour Smooth SVG Spline Curve & 10-Day Range Bars**
   - Custom Catmull-Rom Bezier temperature trajectory + hourly rain probability bars.
6. **🍃 Real-Time Air Quality (AQI) & Lifestyle Wellness Advisor**
   - Live `PM2.5`, `PM10`, `NO₂`, `O₃`, and `US AQI` telemetry + AI-calculated scores for Outdoor Running, Smart Wardrobe, Stargazing Visibility, and Solar Vitamin D windows.
7. **🔊 Web Audio Zen Soundscape + Voice Search & Voice Briefing**
   - Procedural Web Audio API soothing rain/zen sound generator (zero external MP3 files required), Web Speech API voice search, and spoken weather briefings.
8. **🌐 8 Built-In Languages (i18n)**
   - English, हिन्दी (Hindi), Español, Français, Deutsch, 日本語 (Japanese), العربية (Arabic), and 中文 (Mandarin).

## 🚀 Push to GitHub & Enable GitHub Pages

```powershell
cd weather-app
git init
git add index.html README.md
git commit -m "feat: launch BreezeAtlas 2026 production weather & country app"
git branch -M main
git remote add origin https://github.com/Ambikasabhlock/weather-app-2026.git
git push -u origin main
```

Once pushed, go to **Settings → Pages → Branch: `main` → Save** on GitHub to publish your live link!
